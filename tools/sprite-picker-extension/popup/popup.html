How to use
  1. Open the level editor (/editor/) in a tab — or, with no tab, type the PICKER CODE its Atlas Manager shows
  2. Browse to a sprite-sheet page (any site: Inject picker on this tab below)
  3. Tap ⊕ (bottom-right), click the sheet
  4. Click detected sprites to select; pick the atlas and ADD / REPLACE
  5. SEND TO SHMUPX → Atlas Manager, or the editor's inbox
