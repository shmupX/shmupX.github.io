shmupX House Style

One type system and one set of named color tokens for the launcher (dashboard, OSD, save picker) and the level editor. The three launcher themes each fill in the same token names, so a theme is one short block, and the Glow color tweak moves every green on the XBOX theme at once. The tokens live in /house-style.css.

This page is drawn from those tokens. Switch the theme or the Glow color and all of it follows, the same way the launcher does.

Using the tokens

  • Load /fonts/launcher.css, then /house-style.css, before a page's own styles.
  • Write colors as tokens, like var(--accent). For a see-through version, mix the token: color-mix(in srgb, var(--accent) 40%, transparent).
  • A green that isn't a token is written on the Glow hue, oklch(L C calc(var(--h) + n)), so it follows the tweak too.
  • Theme palettes, controller face buttons and art (gradient stops, brand marks) keep their own colors.
