Chrome extension · Manifest V3

shmupX
Sprite Picker

Cuts the sprites out of any sprite sheet on the web and sends them into the level editor's Atlas Manager — an open editor tab first, or an inbox the editor picks up when it opens.

Download ↓ ZIP · UNPACKED EXTENSION
INSTALL
  1. Unpack the zip. It is one folder, shmupx-sprite-picker/.
  2. Open chrome://extensions, turn on Developer mode, press Load unpacked and pick that folder.
USE
  1. Open the level editor in a tab. The popup says EDITOR ONLINE when it sees it.
  2. Browse to a sprite sheet (spriters-resource.com just works; elsewhere, press Inject picker on this tab in the popup).
  3. Press ⊕ bottom right, click the sheet, click the boxes you want.
  4. SEND TO SHMUPX — the editor comes forward with the sprites on top of its Atlas Manager, tagged NEW.
  5. No editor tab? Type the PICKER CODE the editor's Atlas Manager shows into the popup once, and sends wait in an inbox until that editor opens — the road for the desktop app and other devices.
